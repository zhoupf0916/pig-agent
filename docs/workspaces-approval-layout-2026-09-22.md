# 布局、多工作区与审批修复

目标：保留完整白蓝工作台与项目协同分支，修复真实错位；本地项目可关联多个已有目录并为任务选择工作区；审批档位具备明确、真实一致的执行语义。

优先问题与验收：
- P0 审批关闭值被遗漏、跨作者继承自动策略：新任务、续聊和自动化真实遵守选择；网络授权独立，不静默扩大权限。
- P1 布局：手机项目抽屉可关闭、顶栏不重复，窄屏成果不挤压对话，空项目不给无效发送操作；桌面/手机截图与操作验证。
- P1 工作区：创建项目绑定首个目录，支持添加/编辑/移除关联/默认目录；每个任务选择一个工作区并固定路径，编辑项目不改变已有任务；删除关联不删除文件，路径不存在/重复明确报错。

边界：Web 继续绑定控制面与远端Runner，不把浏览器输入的本机路径错误当成服务器可挂载目录。本地目录绑定由客户端提供。多工作区指一个项目关联多个目录，每个任务选择一个，并非自动把全部目录暴露给同一任务。
