## 初步发现

1. 扩展详情只有正文，缺附带资源展示与安装/启用入口；操作错误与反馈位于隐藏的列表区域。
2. 云端资源种类变化只清理编辑状态，未清理旧预览/创建状态，可能显示错误种类操作。
3. 当前没有运行本机服务；本次使用隔离数据、模拟模型，不读取用户密钥、不启动本机Docker、不更改线上服务。

后续随实际验证追加，不以夹具截图冒充云端集群验收。

## 已实现

- 生成文件不再抢走中间对话视图；文件树照常刷新，用户主动打开内容。
- 发送请求失败后先查询权威 session；确认消息未接收、任务未运行时恢复草稿并移除乐观消息，刷新保留。状态未知不自动重发，新草稿优先，不覆盖其他会话。
- 新上传回执使用显式 `synthetic: attachment`，资料记录归到下一轮执行过程，不伪造“没有最终回答”的用户轮次；上下文也不把回执当原始用户目标。旧历史不通过文字匹配擅自改写。
- 云端专家/技能种类变化清理旧预览和创建状态。
- 扩展详情展示脚本/参考/模板，支持原地安装和启用，反馈/错误直接可见；本机设置内跳转资源会关闭设置（有未保存配置仍走原确认机制）。专家方法和完整技能指南按需展开。
- 新增4个原创中文包：API契约体检、发布就绪检查、CSV数据质量、会议行动整理。各1位绑定专家、1项技能、1个只读标准库Python脚本、参考标准和报告模板。现有11个包保留，共15包。无自动安装依赖或执行脚本。

## 验证口径

新增 `scripts/smoke-core-market.mjs` 使用系统临时独立数据、真实本机HTTP服务、脚本化SSE模型和原生文件工具。模型确定性只用于触发流程，不是模型任务质量评测。浏览器创建项目/绑定目录/上传附件，验证批准前文件不存在、刷新仍等待、批准后实际写入与读回、继续对话无重复、503草稿恢复、两工具批次拒绝第一项后均不写入、市场安装/启用/专家绑定/斜杠技能选择与持久化。

浏览器实测中还发现并修正：市场“开始使用”只改变hash却被设置弹层遮挡。修正后从详情到专家选择及实际绑定全部通过。

```bash
pnpm build
node scripts/smoke-core-market.mjs
PIG_SMOKE_DATA_DIR=/tmp/pig-core-status-review node scripts/smoke-conversation-experience.mjs
```

旧构建的缺陷截图在 `data/core-market-review/before`，当前在 `data/core-market-review/after`；抽选无敏感信息的前后截图归档到本页证据目录。默认1440×900与390×844；现有状态回归另含320px、云端确定性页面夹具、设置保存刷新与断流状态。没有启动Docker、调用付费模型、部署线上或声称本次跑过真实控制面/Runner集群。
