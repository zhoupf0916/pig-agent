## 第一阶段：开发者页

协议在 `packages/contracts/src/debug-trace.ts`。本机服务把调用记在进程内存，单会话最多 200 条，默认不记录正文。`Authorization`、Cookie、API Key、token、URL 查询参数和 `sk-` 会脱敏。清空视图只清调试列表，不删执行结果；删除会话会丢掉该会话的调试记录。调试记录不写入 `events.jsonl`。

本机 Pig 循环记录模型、工具、审批和一次真实沙箱探测。探测未完成或失败时，有效沙箱写「未采集」，不用界面开关填数。远端 Runner 在任务结束时交出一份已脱敏快照，控制面 `GET /v1/runs/:id/debug` 沿用原运行的读取权限。Electron 菜单「开发」里的「打开页面开发工具」只打开页面 DevTools，不代替上述列表。

对话检查器增加「开发者」页：本机成果面板、远端成果面板，以及云端「成果与过程」。页内有搜索、失败/进行中筛选、自动滚动、时间线、脱敏详情、错误列表、导出和清空。

## 当前实况（2026-09-23 收尾）

远端 `remote.mjs` 已 16/16。真实 `cloud-proof.txt` 和 bubblewrap 由该次复测确认。本轮没有重建 8892，也没有动 8890。

调试记录除了单会话 200 条，还有总上限：最多 32 个会话、单条 JSON 不超过 65536 字节、全部保留不超过 2MB。超出后丢掉最早的会话或条目，并在条目上写明截断原因。对象字段超过 40 个也会截断，不能只靠缩短字符串。

本地审批结束时按从开始到批准或拒绝的整段时间重算耗时，不再沿用初次 staging 的 duration。批准后的 `op.output` 写入该条目，开发者页「响应」里显示为执行结果。

只读工具最多同时 3 个，失败先收成 settled，不会变成未处理拒绝。取消后不再启动窗口之外的读取。计时从各自的 `executeTool` 开始算到结束。写入仍按调用顺序执行。没有并行相对串行的收益测量，这些数字不表示加速。

长历史把目标、约束、待办和已配对的审批摘进一条有 4000 字预算的用户说明。孤立 tool 消息和不完整的 tool_calls 不会送进模型。压缩后的非系统消息不超过 80000 字。

桌面远端开发者页有「下次远端运行记录正文」。默认关，不复制到新会话。只有当前会话显式为 true 时，首次创建和后续 follow-up 才带 `debugContent: true`。本机「记录完整内容」不会打开远端正文。读取远端调试走原来的运行权限；不能通过桥接 POST 去打开采集。

取消后的检查点仍会拦住同一条用户消息的自动重放，后续写入不会执行。用户显式继续未完成的小队成员时，先丢掉这个已停止、不再执行的检查点，再开始该成员的新回合。拒绝和重试接口仍然不会自动重放。

### 固定任务基准

脚本：`node scripts/mock-task-bench.mjs`。报告：`docs/evidence/runtime-debugger-bench-2026-09-23/report.json`。Node v24.21.0，darwin arm64。每类冷、热各 5 个成功样本，失败 0。`PIG_DESKTOP=1` 不读 dotenv，数据目录和工作区都是临时目录，已去掉模型密钥。不连接 8890 或 8892。

冷启动是父进程 spawn 到子进程打印 ready，发生在任务之前。热样本是同一进程预热一次后连续 5 次，启动时间只算进程内准备。首字只在客户端收到文本 token 时记录，审批和取消为 null，并单独记录首个工具事件。开销是每个样本的总耗时减去该样本实际累计的模型等待，再取这些差值的分位数。重连耗时单独列出，不加进总耗时。下面是 P50/P95，单位毫秒。
