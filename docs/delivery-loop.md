# 可审阅、可恢复的本机工作台

适用范围：本机 Pig。保留原有 Codex / Cloud 后端，其内部工具执行不经过此审阅链路。

## 使用流程

1. 新建任务，打开聊天顶部的 **执行与验收**。
2. 核对绝对工作区路径。在“执行设置与预算”选择宿主机或 Docker、网络策略和预算。任务首次运行或保存设置后绑定该目录，修改全局工作区不能把旧变更单带到新目录执行。
3. 发送任务。默认写入、编辑、补丁、删除、移动文件和所有 shell 命令先生成待批准变更单，不立即执行。
4. 审阅完整目标路径、差异或命令，逐项批准或拒绝。快照与当前磁盘不一致时阻止覆盖，需重新生成变更。
5. 批准后点击 **继续任务**。保留已执行工具记录，模型接着验证和交付；不会通过删除历史重跑原目标。
6. 在验收清单确认磁盘内容与执行快照一致，检查剩余计划和错误。文件内容核验并不自动证明代码测试或业务目标正确。
7. 文件变更可撤销，先检查当前磁盘仍等于执行后快照。撤销成功会新增待核验步骤，避免沿用旧“完成”状态。

同一会话的写入、批准、恢复请求有互斥保护；重复批准返回冲突，不再次写入。操作前持久化 `applying`，服务中断后不自动重放。出现错误或未确定结果时，需要用户核对实际文件并点击“已人工核对，解除阻塞”。这并非跨文件事务保证：中断可能留下部分操作结果。

## 上传与模板

在抽屉点击 **上传资料** 或拖入文件，每个最多 5MB。资料存到绑定工作区的 `uploads/`，带唯一文件名，保留上传消息和可撤销快照，不覆盖同名文件。文本可直接通过 read_file 阅读；PDF、Word、图片等二进制资料需要对应解析工具，并不承诺已自动提取正文。

“任务模板”包含代码审查、整理资料、生成报告、测试与修复；可保存和删除自定义模板。选择模板仅填入草稿，不自动发送或执行。

## 用量与预算

显示模型调用轮数、输入／输出 token、模型耗时和按用户填写单价估算的费用。默认每任务 40 轮、100000 token；费用上限为 0 时不限制费用。输入与输出单价单位均为每百万 token，币种由用户保持一致，不内置可能过期的价格。

每轮请求前检查调用、token 和费用预算，同时限制输出长度。供应商提供 usage 时采用该值；缺少 usage 或请求中断时采用保守估算并明确标记。失败请求仍计入调用轮数；底层兼容性重试可能产生额外 HTTP 请求，因此这不是供应商账单或精确扣费限额。

预算不足会停止并保留上下文。修改预算后可继续，无需重新发送用户目标。DeepSeek 思考字段会保留并按协议回传，旧会话缺失该字段时使用非思考模式兼容恢复。参考 [DeepSeek 官方协议](https://api-docs.deepseek.com/guides/thinking_mode/)。

## Docker

Docker Desktop / Docker Engine 必须已启动，并预先下载所选镜像。默认镜像：

```sh
docker pull node:22-alpine
```

选择 Docker 后，**shell 命令**由独立短生命周期容器执行：仅当前工作区绑定挂载到 `/workspace`；根文件系统只读；`/tmp` 为 128MB 临时盘；512MB 内存、1 CPU、128 进程；删除 Linux capabilities，禁止提权，使用宿主用户 UID/GID；默认无网络，不挂载宿主用户目录或 Docker socket。模型请求及文件工具仍由本机服务处理，不应把整个应用称为容器隔离。

依赖请安装到工作区（例如本地 node_modules 或 venv）；容器临时目录和全局环境不会跨命令保留。网络需要明确开启。镜像缺失或 Docker 不可用时返回错误，**不会自动退回宿主机**。命令完成、停止或超时后清理容器。宿主机命令停止时会终止进程组。

任意 shell 命令不能自动生成完整文件撤销快照；命令批准页明确提示不能自动撤销。可以使用文件工具获得逐文件的审阅与撤销。

## 数据与限制

- 会话与工具检查点：`DATA_DIR/sessions/`。
- 执行设置、完整文件前后快照和操作日志：`DATA_DIR/workbench/`。
- 自定义模板：`DATA_DIR/task-templates.json`。
- 快照仅支持普通文件，每文件最多 5MB；文本工具写入限制为 400000 字符。目录移动／删除不能作为可撤销操作，需逐文件处理。
- UI 差异预览最多 12000 字符，快照保留完整内容；文件上传直接由用户动作执行，不再额外生成待批准请求。
- 默认审阅模式下，定时任务遇到写入或命令也会暂停等待审阅；适合先读后评估，不能宣称后台修改已完成。
- 同目录内的外部程序并不共享本服务锁。批准和撤销会核对快照，但不构成操作系统级文件锁或恶意并发攻击防护。

## 已完成验收

- 自动化覆盖：批准前不写入、并发／重复批准、保留工具历史恢复、预算阻断、外部修改冲突、工作区切换、符号链接越界、二进制移动／删除／上传与撤销、模板持久化、遗失工具结果修复、已批准命令停止、DeepSeek 推理字段和用量回传。
- 真实 DeepSeek：生成写文件变更单 → 确认批准前磁盘无文件 → 浏览器批准 → 继续任务 → read_file 核验 → 三项计划完成；浏览器撤销后文件消失。
- 新会话再次实测思考字段保留和恢复，完成后磁盘字节与批准快照一致，无剩余计划。报告在 gitignored `data/delivery-validation/final-report.json`。
- 浏览器实测上传本地资料，生成唯一文件名和消息记录。
- 真实 Docker：容器工作目录 `/workspace`、看不到 `/Users` 和 Docker socket、网络路由表为空、文件写回挂载工作区、命令超时触发清理。
