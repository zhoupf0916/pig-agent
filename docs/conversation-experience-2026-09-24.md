# 对话体验与上下文用量

日期：2026-09-24。Cursor 完成主体实现，Codex 独立审查、真实浏览器操作和回归后集成。本记录描述源码和本地验证，未部署腾讯云生产服务。

## 产品行为

- 本机与云端共用逐轮对话展示：用户消息、默认折叠的执行过程、最终回答分开。过程降低视觉权重，不做模糊滤镜。展开可查看完整进度和工具输出。
- 工具前的进度文字不算最终回答；失败、取消、等待批准、没有最终回答分别展示。审批操作保持原有权限和后端执行边界。
- 白色对话画布、紧凑执行入口；输入区和底部附件、技能、用量、发送操作分层。保留协作作者、每轮附件链接和文件工作台。
- 输入框旁展示最近一次模型调用的已用字符、输入预算及占比。详情包括系统指令、工具定义、消息、省略与截断数量、采集时间和调用标识。
- 这是字符预算估算，不是供应商的模型 token 窗口，也不是累计计费 token。无数据显示未采集；Codex 不回传对应输入构成时显示未知。不会输出系统提示正文或模型密钥。
- `context_usage` 在预算检查通过后发出，并持久化到会话和事件日志。远端适配器、云端快照、刷新和前端订阅保持一致。切换会话立即清除旧用量。
- 手机用量详情为视口内面板，支持明确的关闭按钮、Escape 和关闭后焦点返回。

## 独立审查发现及修复

先加入会失败的行为测试，再修复：工具前导文字被误判为回答、历史取消状态被新一轮覆盖、预算拒绝时仍伪报新调用、重复“继续”被关联到旧运行的失败状态。

浏览器自审还修复了：第二轮替换第一轮工具记录、协作作者和附件丢失、390px 用量弹层右侧裁切、切换会话时短暂显示上一会话用量。切换会话问题通过延迟新快照的浏览器测试先复现，再清除旧指标。共享展示字段定义在 contracts，避免应用间复制协议。

## 验证证据

- 全量测试：169 个文件、939 项通过。
- 定向回归：9 个文件、29 项通过，包含独立审查测试。
- 架构检查、contracts/server/web/cloud/worker 类型检查通过。
- Web、控制面、网关、Worker、Runner 构建通过。Web 主包仍超过 500 kB，这是已有构建告警，未作为本次性能改进宣称。
- 独立浏览器冒烟覆盖本机和云端的空态、两轮、执行中、审批、失败、取消，共 12 个场景，每个测试 1440×900、390×844、320×844；另外保存用量详情和展开的完整工具输出，共 39 张截图。检查作者和附件归属、默认折叠、完整日志、弹层边界、键盘开关、焦点返回、会话切换旧指标清除，浏览器未记录页面异常。
- Codex 实际通过浏览器发送三轮消息，使用真实本机 API、运行循环、工具与 SSE，模型由本机模拟服务替代；确认流式回答、最终总结、第一轮日志在第三轮后仍可展开，以及刷新后的用量持久化。最终一次样例为 9,414 / 80,000 字符，其中系统指令 3,569、工具定义 4,777、消息 1,068，分项之和等于总量。事件日志与快照一致。

## 复现

```bash
pnpm install
pnpm --filter @pig-agent/web build
PIG_SMOKE_DATA_DIR=/tmp/pig-conversation-smoke node scripts/smoke-conversation-experience.mjs
```

脚本要求指定仓库 `data/` 之外的输出目录，每次创建独立 `run-*` 子目录，结束后打印证据路径。屏蔽模型环境变量并跳过 `.env` 加载；不读取本机账号配置、不调用付费模型、不启动 Docker。使用 18791、18792 两个本地端口，结束后关闭自己启动的服务。运行前确认这些端口空闲。

```bash
pnpm exec vitest run apps/web/src/lib/conversation-review.test.ts apps/cloud/src/transcript-review.test.ts apps/server/src/agent/context-usage-review.test.ts
pnpm check:architecture
pnpm typecheck
pnpm --filter @pig-agent/cloud typecheck
pnpm test
```

## 验证边界

云端界面场景使用模拟控制面快照和事件；本轮未运行新的 PostgreSQL/Runner 集群集成，也未部署生产服务或消耗真实模型额度。上下文用量只反映最近一次已发起调用的输入字符预算，不包含用户尚未发送的草稿；不能据此推断真实模型剩余 token 容量。最终文字由模型生成，界面不伪造成功总结。
