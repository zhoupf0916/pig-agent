# 输入框胶囊与 Web 文件夹工作区

问题：用户截图显示输入框下方被两条全宽折叠栏和容器说明撑开，视觉臃肿；Web创建项目只有工作区名称，本地目录按钮仅存在于客户端，入口与用户预期不符。

验收：两枚紧凑胶囊与发送按钮在底部工具栏，点击浮层选择专家/技能和审批/网络，互斥打开、Escape/外部点击关闭，桌面手机不溢出；Web创建普通项目可选择文件夹，显示文件数与上传边界，创建后真实云任务可读取子目录文件。客户端直接绑定目录能力保留。

执行边界：Web上传一次性文本副本到云端，不伪装成持续挂载用户电脑目录。最多400个UTF-8文本文件/单文件200KB/共2MB，依赖、敏感路径、二进制文件不导入。用户可选择空白云工作区。

## 完成与验证

胶囊已替换原两条全宽折叠栏，与图标发送按钮同行。空态弹层向下展开，桌面限制宽480px，不遮挡输入；执行时向上。已真实验证互斥、Escape、外部点击关闭、1440×900/390×844无横向溢出，人工检查折叠/展开截图。

Web创建普通项目新增「选择本地文件夹」按钮，自动带入项目/工作区名称，显示文本文件与跳过数量；支持改用空白工作区。真实Chrome目录选择器以临时目录作输入，两文件包含子目录，`.env`和`.npmrc`被跳过，POST201成功，工作区显示README.md与src/demo.ts。

三个真实Docker任务验证初始种子导入、实际write_file/read_file、幂等重放固定原种子、后续快照优先、新会话采用更新种子。公开运行元数据不返回源码，跨owner与危险路径被拒绝。证据见[导入验证](project-folder-import-2026-09-22.md)。运行模型为mock、容器与文件操作真实，不宣称真实模型质量。
