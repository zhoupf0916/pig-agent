# 社区精选技能与专家

2026-09-24 首批新增六个包，每包一项技能和一位专家。已有五个基础包保留，总计十一包。内容为中文精简改编，不是原作者官方发布，不复制外部工具权限、自动安装脚本或不适用的流程门禁。

| 包 / 专家 | 用法示例 | 可交付内容 |
| --- | --- | --- |

Web：设置 → 扩展与 MCP；桌面：设置 → 插件。查看内容后安装并启用，再在任务中选择专家或技能。选择专家会引用同包技能。安装按账号/本机隔离，不向全部用户自动启用，也不把所有包塞入每次对话。
