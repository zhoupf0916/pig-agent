# 账号申请、审批与密码登录

用户从 Web 或客户端输入用户名、密码、显示名称提交申请；管理员在“账号与配额 → 账号申请”批准后，用户使用原密码登录。待审批和拒绝的账号不能登录。用户名忽略大小写，为 3–32 位字母、数字、点、下划线或短横线；密码长度为 10–128 位。

密码以随机盐 scrypt（N=16384,r=8,p=1，64 字节派生密钥）保存，不向管理员或接口响应返回。批准事务锁定申请，只能创建一次成员身份；重复相同审批幂等，冲突决策拒绝。批准和拒绝后清除申请表中的密码哈希。审核操作写入审计日志。

Web 使用 12 小时 HttpOnly / SameSite Strict 会话，HTTPS 时启用 Secure；写请求检查 Origin。登录/申请共享数据库全局 120 次/分钟限制，密码账号额外限制 10 次/分钟。客户端登录的会话凭证只存在系统密钥存储中，原始 settings.json 和 Web 渲染进程不会收到凭证；重启保留连接，退出会撤销云端会话并清除本地密钥。并发登录/退出以最新意图为准，迟到登录凭证会被撤销，不能重新写回；控制面离线时仍清除本地密钥，远端会话只能等待过期或管理员撤销。

首次本地部署运行 `node scripts/setup-admin-password.mjs`。它仅给尚未绑定用户名的本地管理员生成初始账号密码，并写入权限 0600 的 `data/cloud-local/accounts.txt`；已有管理员密码不会重设。管理页面默认账号密码登录，内部令牌和旧设备邀请折叠为高级兼容入口。已登录管理员可在账号页修改自己的管理员密码，该操作会撤销其登录会话。

目前不提供邮件确认、找回密码或自动重新提交被拒申请。用户应联系管理员处理账号问题。内部 Bearer API 和旧版设备令牌兼容保留；普通用户不需要复制令牌。

## 实际验证

- `scripts/smoke-password-accounts.mjs`：真实 Chrome 申请、待审登录拒绝、管理员密码登录与页面批准、批准用户登录和刷新、幂等/冲突审批、成员越权拒绝、拒绝申请、错误密码、哈希存储和退出。
- `scripts/smoke-desktop-password.mjs`：真实 Electron 隔离用户目录，登录后渲染进程和普通设置不含凭证，退出进程并重启恢复身份，登出撤销远端会话并清空系统密钥；使用受控延迟响应实际验证登录/退出竞态，迟到登录返回 409，系统密钥保持清空。
- 证据在 `data/password-account-evidence/`；测试仅使用本地隔离集群，不代表公网认证容量测量。
