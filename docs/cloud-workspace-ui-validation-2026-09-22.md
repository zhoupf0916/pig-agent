# 共享工作台 UI 验证

实现：`apps/web/src/cloud/CloudWorkspace.tsx`，同源云端 API；桌面复用同一组件，通过 `/api/remote` 连接控制面。Web 无本机运行或本机文件入口。组织、共享项目与背景、成员邀请、会话、审批、成果均使用真实后端。

交互：工作空间与会话导航，远端对话主区域，按需打开成果/步骤侧栏；白蓝色视觉与 390 px 手机布局。默认审批写入，明确共享范围。状态与审批卡片避免重复显示底层运行占位消息。

流：fetch SSE 按持久序号去重，快照是会话状态权威。只对最新未结束运行呈现增量文本，历史及已完成运行重放不产生第二条回复。异步成果读取校验会话与运行身份；账号代际隔离旧轮询、SSE 和退出前响应。

2026-09-22 实际验证：本地 8892 控制面/真实 Runner 容器、模拟模型，两个独立 Chrome context，各用不同普通账号。

1. 登录、创建组织、邀请编辑者、创建含共享背景的项目，通过 UI 完成。
2. A 创建任务，B 打开稳定会话链接，在运行中看到用户作者与提问；A 审批后 B 在终态前观察到多次增量回复。
3. 完成后恰好一条助手回复，刷新仍恰好一条；成果预览匹配真实容器 `PIG_CLOUD_CONTAINER_OK`。
4. B 续聊，A 在同一会话审批，运行成功。
5. 人工延迟 A 的项目元数据响应，在同页退出后登录 B，释放 A 旧响应，B 中不出现 A 私有项目。
6. 桌面 1440×900、手机 390×844 截图已实际查看；手机无横向溢出。初版冗余审批消息与错误“个人空间”临时标题已修复并重新截图。

证据：`data/cloud-workspace-evidence/report.json` 与截图；保留初版对比于 `data/cloud-workspace-evidence-first-pass/`。复现脚本：`node scripts/smoke-cloud-workspace.mjs`（需要隔离 mock 集群和本地忽略的测试账号 env；只向隔离集群写入验收项目）。Web TypeScript 与构建通过。

限制：这些是本地 mock 模型容器验证，不代表生产容量或真实模型首字耗时。浏览器显示权限来自控制面，服务端仍执行最终授权。插件与本机 computer use 保留在桌面本机工作台，不通过此云端界面提供。
