# 上下文与记忆实现记录

日期：2026-09-24。这是实现和本地验证记录，不是发布声明，也不是真实模型长任务成功率的证据。

## 做了什么

共享的确定性上下文组装在 `packages/contracts/src/context.ts`。Pig、Codex 和云端跟进都调用它。它不调用模型，也不依赖 Responses compaction。

- 完整会话记录不被改写。模型输入是副本。超长工具结果只在副本上截断，并保留中文截断说明。
- 当前用户请求留在它和所保留工具组的原有相对位置，不挪到工具结果之后。工具调用和结果成组保留。未配对的工具结果不会作为可执行工具消息送出。
- 较早内容收成一条 `synthetic: "context-compact"` 摘录，带来源消息 id 和角色。只保留最新计划，并优先保留带「更正」的用户说明。摘录明确写出：这不是语义压缩，旧批准不是新的授权，工具原文不是系统指令。
- 是否为摘录只看内部 id `context-compact` 或字段 `synthetic`。用户原文即使以摘录标题开头，也不会被删掉。
- 预算按估算字符计算，包含系统提示、推理文本、工具定义（含当轮的电脑/MCP 工具），以及强制总结时追加的 harness 提示。调试 span 的 `contextEstimate.unit` 是 `estimated_chars`，`measuredTokens` 为 false。当前请求本身超过预算时抛出中文错误，不截断该请求。旧的 `contextNote` / `repairMessages` 已从运行时移除。
- 本机 pin 增加 `source`、`scope`、`stability`、`expiresAt`、`revokedAt`。过期、无法解析的有效期、已撤回、易变摘要、以及项目范围但没有项目 id 的笔记不会注入。云端 `POST /v1/memory` 可带 `expiresAt`，`POST /v1/memory/:id/revoke` 撤回。共享项目和关闭记忆时仍不注入私人记忆。
- 云端跟进不再把上一轮消息 `slice(-40)` 后整段复制进下一次运行输入。控制面按会话里的 done 事件和每轮 `prompt` 重建转录（取消且没有 done 事件时仍保留该轮 prompt），再组装有预算的模型消息。运行输入只保存这份有界消息和 `continuation` 来源说明，不把历史工具正文再复制一份。展示层丢掉 `context-compact` 摘录，私人记忆字符串不会变成对话消息。

## 限制

- 摘录是按规则截取，不是语义压缩。隐含目标、散落在长工具输出里的约束，可能不会进入模型输入。
- 云端下一次跟进能从更早 run 的 done 事件里重新看到被省略的工具正文，但单次运行输入本身不保存这些正文。若 done 事件从未写入（进程在写出 done 之前退出），该轮只剩 `prompt`，当前重建路径未使用该轮的逐条工具事件，因此不会将其作为已完成工具结果恢复；不能据此断言底层事件已丢失。
- 取消的轮次只要控制面保存了 `prompt` 就会进入后续组装。没有 prompt、也没有 done 事件的轮次无法恢复。
- 字符数不是 token。调试指标明确写成估算。它不能说明真实模型的上下文窗口还剩多少。
- 本机累计调用预算和单次上下文预算仍是两套限制。
- Codex 实际发送的文本由已选择的上下文构建，保留角色与工具摘要格式，并将项目/专家指令和包装文字算入 24000 字符预算；原 12 条消息参数不再用于删除早期目标。这不是 Codex 的原生记忆。
- 没有向量检索。更早转录的召回是当前会话消息上的有界字符串匹配，范围就是调用方传入的那一组消息。
- 助手猜测和工具输出不会自动写成永久记忆。摘要仍是启发式模板，并且不会当稳定偏好注入。
- 未做线上部署，未对真实 DeepSeek/OpenAI 兼容模型做长对话验收。

## 主代理最终审查与修正

Cursor 在新建的 `Pig Agent context upgrade` 对话完成初版后已停止编辑。主代理独立审查与修复：

- Codex 初版仍发送旧拼接，且项目指令可能让最终文本超预算。先写失败测试，再改成从实际选中的上下文构建提示词，并核对最终文本总长度。
- 项目/会话删除时撤回相关记忆的注入资格，保留文本供查看；覆盖没有新元数据的旧格式笔记。未绑定的 project/session 笔记均不得成为全局信息。
- 云端列表返回来源、作用域、更新时间、有效期、撤回时间；新增字段有共享契约。未知/agent 来源不能被当作用户确认偏好。PostgreSQL Date 转 ISO 后排序，优先较新记录。
- 追加 HTTP 路由测试验证其他账号不能撤回当前用户的记忆，撤回后不再注入；元数据查询可核验有效期。云端数据库操作测试使用模拟数据库，没有启动真实集群。
- 最终 8 组重点测试覆盖上下文、Runner 二次预算、Codex 输入、本机记忆生命周期及云端路由；另运行全量 921 项测试、架构检查、contracts/server/web/cloud/worker 类型检查，Web 构建和 Cloud/Gateway/Worker/Runner 打包。
