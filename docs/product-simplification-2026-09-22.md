# 工作台简化与扩展能力

目标：对话看结论，过程按需展开，成果只保留一处主要入口。创建专家与技能只需描述目标，模型生成草稿后由用户检查创建。桌面操作保留本机授权边界。

## 验收项
- 日志按工具调用合并；原始 token、JSON、心跳不占主视图。审批处理后状态及时同步。
- 一句话生成专家/技能草稿，允许编辑；有效配置保存后可被任务加载，错误可恢复。
- 插件包可预览、导入、启停、移除。严格校验，不执行导入内容中的脚本；插件技能与专家进入现有运行时。
- Computer use 仅桌面本机 Pig 可用，有启用/撤销与逐次原生确认；Web/Runner 无宿主机桥接权限。操作失败给出真实权限状态。
- 构建、相关回归、浏览器桌面/手机截图、实际原生能力验证；不能把权限缺失写成验证通过。

## 决策与范围
先支持声明式 pig-plugin-v1 专家/技能包，不引入任意代码安装或虚构插件市场。示例见 docs/examples/writing.plugin.json。插件安装于数据目录，默认关闭；启用后专家与技能在后续调用中可见，运行中已加载指令不回收。模型与网络请求仍沿用现有设置。插件内容为第三方指令，需预览审阅。

Computer use 使用 Electron 私有进程桥接，独立于工作区文件工具。macOS 原生权限由系统管理，不能自动批准。

## 进度
正在实施与验证，尚未完成验收。已有白蓝主题与 SSE 修改保留，未覆盖用户会话。

## 未完成与边界

- 此Mac的辅助功能权限未授予；真实原生观察返回权限拒绝，鼠标/键盘成功路径尚不能验收。需要用户在 macOS「系统设置 → 隐私与安全性 → 辅助功能」授权当前运行的 Electron/Pig Agent 后，继续用无敏感内容的测试窗口回归。没有自动更改系统权限。
- 当前computer use依赖辅助功能树，不是视觉模型驱动的任意屏幕识别；截图不会发送给模型。仅macOS、本机Pig，Codex和远端不可用。
- 插件为声明式专家/技能包，不包含MCP连接器、任意代码插件或在线市场。加载到运行中任务的旧指令不会因停用而回收。
- 用户新增技能与插件的容器分发尚未实现，不应把本机安装理解为所有Runner全局安装。
