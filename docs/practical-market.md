# 实用专家与技能市场

在「设置 → 插件 / 扩展与 MCP → 发现扩展」搜索用途，点击「查看内容」，审阅技能指南、脚本、参考文件与模板；详情中直接安装，再明确启用。安装默认停用，不自动运行脚本，也不会安装Python依赖。

启用后点击「选择专家与技能，开始使用」，在专家列表绑定到任务，或在输入框输入 `/` 搜索技能。自动化沿用技能选择与任务快照机制。当前目录共15个包：原有5个基础包、6个社区精选包，以及本页4个原创中文包。

| 工作包 / 专家 | 适合交给它的任务 | 附带工具 | 交付与边界 |
| --- | --- | --- | --- |
| API契约体检 / 接口排障工程师 | “检查这份OpenAPI JSON，找出缺少响应定义和需核对鉴权的接口。” | `inspect_openapi.py` | 路由清单、响应和鉴权声明；静态检查，不自动请求接口，不解析外部引用 |
| 发布就绪检查 / 发布验收负责人 | “整理这个版本的构建、测试、迁移、回滚证据，列出阻断项。” | `check_release.py` | 输入JSON检查清单；必需项build/tests/migration/rollback，缺项不会报ready；不执行部署 |
| CSV数据质量 / 数据核验专家 | “检查附件的缺失、重复、列宽异常，给出清理建议，保留原文件。” | `check_csv.py` | 原始数据不变；全行重复不等于业务主键冲突，不自动删除数据 |
| 会议行动整理 / 会议行动协调员 | “把这份记录整理成决定、行动项和待确认问题，不替参与者承诺日期。” | `count_actions.py` | 统计Markdown复选框及原始行号；不从自然语言自动推断完成状态、不发送消息 |

每个包包含一个绑定专家、一项技能，以及三个资源文件：`scripts/*.py`、`references/checklist.md`、`assets/report-template.md`。技能正文给出输入、步骤、交付、验证和权限说明。脚本使用Python3标准库，只读本机输入并向stdout输出JSON，上限5MiB，不联网。执行仍服从工具审批和原生沙箱，Python不可用时明确报错，不能谎称已验证。

这是本仓库原创实现，不依赖额外下载的社区代码或授权；已有社区包保留原来源与许可证。包目录源码见 [practical-catalog.ts](../packages/contracts/src/practical-catalog.ts)。

## 验证

```bash
pnpm exec vitest run apps/server/src/store/practical-catalog.test.ts
pnpm build
node scripts/smoke-core-market.mjs
```

行为测试核对安装默认停用、启用后专家绑定可用技能、同名安装不覆盖；四个脚本各使用真实Python进程核对结果、输入不变与文件不存在时的错误。浏览器验收覆盖查看资源→安装→启用→专家绑定→斜杠选择及持久化，详情见 [回归记录](core-market-review-2026-09-26.md)。这不等于对任意真实模型的技能执行质量完成评测。
