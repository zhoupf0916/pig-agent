# 0.1.1 回归记录（2026-09-21）

环境：macOS arm64、Node 24、pnpm 11.19.0、Electron 44.4.3、Codex CLI 0.153.4。模型密钥仅从本机配置读取，未写入报告或安装包。

## 修复

- Codex 桌面缺少独立认证链路：增加 Responses 地址、独立密钥、同源显式复用与真实 CLI 连接测试。
- 真实 CLI 无法解析生成模型目录：补齐 `experimental_supported_tools`，增加真实二进制协议回归。
- 停止发送 SIGTERM 后错误跳过 SIGKILL：改为检查实际退出状态，并处理启动前取消。
- 空任务不能直接发送、初始化覆盖发送状态：自动创建任务并在启动加载期间禁用输入；同步锁阻止快速重复发送。
- 首次配置允许空远程密钥、目录无效：增加校验并保留已保存凭据状态。
- 同进程 JSON 并发写临时文件冲突：随机独占临时文件、原子替换和用户私有权限。
- 错误信息丢失关键尾部、产物读取符号链接越界、历史助手消息掩盖本轮空回复：修复对应边界。
- 连接测试使用独立临时 Codex home，避免改写正常任务的信任配置。

## 验收边界

本轮覆盖当前本机 Web / macOS 桌面及已有适配器测试，不代表所有生产场景无缺陷。没有连接真实远程 Cloud 集群，也未验收 Windows / Linux 桌面分发。Codex 需要外部 CLI，使用自身 workspace-write 沙箱，不经过 Pig 写入审批；多轮为近期对话拼接。macOS 包仍未签名、公证，没有自动更新。模型网络与提供商延迟仍可能导致超时，界面支持停止和重试。
