# 项目与自动化体验改造

## 目标与参考

实际操作本机 JoyDesk 2.2.2：自动化采用计划/执行记录双视图、模板起步、任务和计划优先的编辑器；项目有独立主页，保持侧栏项目和对话关联。参考信息组织，不复制其品牌、私有内容或绕过审批的设置。

## 基线与验收

- 已有未提交项目共享逻辑保留，基线补丁在忽略目录 data/joydesk-refresh-baseline。
- P0：自定义 cron 编辑后不得被默默改为每日；先写失败行为测试。
- P1：自动化支持搜索、状态筛选、模板、计划/记录切换；保存、暂停、手动触发、记录跳转经过实际操作。
- P1：项目有可刷新定位的主页，对话/工作区/协作入口分开；创建后能找到项目并继续对话，不改变访问权限。
- P1：编辑器有明确分组、摘要、错误反馈、键盘焦点约束；窄屏不横向溢出。
- 验证使用本机隔离 mock 环境和真实浏览器；不反复调用真实模型。

## 决策

保留现有 PostgreSQL 调度与幂等语义；使用 contracts 的 SchedulePlan。Web 创建云端计划；已有设备计划继续显示真实位置与执行语义，不假称某台设备在线。项目主页只呈现后端已支持的能力。

## 进度

- 本轮项目与自动化流程已实际验证；全量回归仍有一项基线失败，见下方记录。

## 已完成与实测

- 自动化：计划/执行记录两个视图，搜索与状态筛选、空态模板、可折叠执行设置、固定保存栏；复用账号安全默认值，不默认绕过审批。记录每 5 秒更新。
- 编辑计划复用 contracts 的 SchedulePlan；自定义 Cron 不再转换成每天 09:00，旧格式时间也从原表达式恢复。每周零天阻止提交。
- 设备计划手动触发没有 remoteRunId 时不再跳转 `/runs/undefined`；显示真实领取记录。网页创建保留云端执行，旧设备计划可继续查看和管理。
- 项目：独立且可刷新的主页（概览/对话/工作区与文件/说明），创建后进入主页；从主页发起对话保留项目归属，文件版本打开对应运行。既有共享/成员操作继续复用控制面权限。
- 侧栏默认折叠未选项目，避免空项目占满导航；当前项目自动展开。
- 实际操作本机 JoyDesk 的自动化列表、创建表单和项目主页作为参考，不复制其私有数据或不安全默认值。

真实浏览器使用隔离 8892 控制面及 Runner，前端 8896；桌面 1440×900、手机 390×844。完整流程：创建暂停的月度 Cron → 改名保存 → 刷新仍保留 Cron → 启用（下一次 2026-10-01 09:15）→ 暂停并刷新 → 手动执行 → 等待 write_file 审批 → 批准 → succeeded → 文件成果。运行 `run_e623db64bfa84f7190b23e29ded93164` 使用 mock，没有调用真实模型。另验证项目创建、刷新、文件版本、对话归属和无效计划错误。

1. 在自动化新建一个暂停的自定义 Cron，改名保存并刷新，确认表达式不变。
