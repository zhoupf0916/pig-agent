# Pig Agent 多端与远端执行计划

更新：2026-09-21。按用户确认的架构调整：只有一个用户工作台，Web 与 Electron 均可选择本地或远端执行；云端是执行能力，不是独立用户产品。管理后台用于管理控制面。

## 架构与权威边界

```text
同一套 Web / Electron 工作台
  ├─ 本地执行 → 本地服务 → 本机执行器
  └─ 远端执行 → 控制面 API → 持久队列 → Worker → Agent 容器
                    ↑                         ↓
              控制面定时调度 ← 数据库 ← 事件、心跳、产物
                    ↑
                 管理后台
```

控制面是远端任务定义、会话、调度、运行状态、取消、资源分配和产物索引的唯一权威。客户端提交操作意图、读取状态和订阅事件，缓存仅用于展示。关闭网页、退出桌面、SSE 断开均不取消远端运行；客户端请求停止后显示“正在取消”，直到控制面确认终态。

执行位置与执行引擎独立：`executionTarget = local | remote`，`engine = pig | codex`。每个会话和定时任务保存自己的执行配置，每次运行保存配置快照；修改全局默认值不能改变已排队任务。旧 `runtime=cloud` 兼容映射为 remote + pig，历史数据迁移需保留可读性。

本地执行保留离线能力，数据和调度由本地服务负责。远端任务和远端定时任务必须由控制面持久化并调度，不能依赖任意一台客户端在线，也不能被本地定时器重复触发。本地任务不隐式上传。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| apps/web | 唯一用户工作台：会话、文件、自动化、执行位置选择、运行状态与成果 |
| apps/desktop | 复用 Web；提供本地目录、系统凭据、本地服务与成果导入 |
| apps/server | 本地执行与离线调度；远端 API 适配和缓存，不裁定远端终态 |
| apps/cloud | 控制面：身份权限、会话和任务、定时调度、队列、租约、资源策略、事件和审计 |
| apps/worker | 按控制面授权领取租约，创建、停止、回收执行容器并上报；不自行决定任务调度策略 |
| apps/admin | 控制面管理后台：账号、模型、配额、运行、调度、节点和审计 |
| packages/contracts | 统一任务、运行、执行配置与事件协议 |
| packages/agent-core（待提取） | 共享 Agent 循环，注入模型、文件、命令与事件接口 |
| infra/ | 本地 Docker Compose、迁移、镜像、备份与部署 |

首期所有后端依赖在本机 Docker 运行，使用 PostgreSQL 持久队列；暂不增加 Redis 或 Kubernetes。远端容器由可信 Worker 管理，控制面校验镜像、资源上限、并发与运行权限。浏览器和 Agent 容器均不能访问 Docker socket。

## 当前基线：已经完成与仍缺少的部分

已完成第一条容器执行链路：控制面持久队列、账号令牌隔离、Worker 租约与心跳、独立容器和网络、真实 Pig 工具循环、模型网关、事件补播、文本产物、取消及崩溃恢复检查。现有本地 remote 适配器已联调。默认模型仍是固定响应的 mock，用于执行链路验收，不能当作可完成任意任务的真实模型服务。

本批已完成：每会话执行位置与引擎选择；原自动化页面创建、编辑、启停与手动触发远端计划；控制面 cron/时区/错过触发策略、事务去重和禁止重叠；原工作台内远端运行记录、日志和成果下载；取消确认与本地进程中断后的状态/消息恢复；后台节点排空及 1–3 并发槽位控制。旧 Cloud 自动化不再由本地定时器触发，可在页面迁入控制面。

尚未完成：跨设备完整会话/项目同步、跨轮持久工作区、正式账号/组织、审批恢复、可配置镜像/单任务资源模板、真实模型渠道管理。当前远端计划保存提示词，不携带本地专家或项目引用；迁移前需显式移除这些绑定并把必要上下文写入提示词。旧独立云任务页仅保留为开发诊断页，不作为产品入口。

验收已加入 Docker CI：多调度调用去重、节点并发/排空与管理员权限、skip/once、控制面重启触发、客户端断流任务继续、状态与消息回放去重。本机验收报告见 `docs/control-plane-acceptance.md`。

## 实施顺序与验收

### 1. 统一执行协议和工作台入口

- 将执行位置与 Pig/Codex 引擎分开，增加会话及自动化级选择，迁移旧 runtime。
- 工作台直接创建、查看、取消远端运行，显示当前执行位置、排队和取消中状态。
- 控制面持久化 conversation、message、run、attempt、event；区分会话、一次运行与执行尝试。
- 客户端通过事件序号补播并重新读取权威状态；发送幂等，重连不重复消息或任务。
- 远端取消先提交意图，控制面确认容器停止后结束；失去连接不伪造成功或取消。

验收：Web 和桌面查看同一远端运行状态；关闭客户端后任务继续，重开可恢复；重复提交只创建一次运行；本地执行回归通过。

### 2. 控制面定时调度

- 控制面保存 schedule、时区、下次触发时间、启停状态、执行配置、重叠运行策略和错过触发策略。
- 调度器在控制面运行，使用事务认领和 `(scheduleId, scheduledAt)` 唯一约束，重复扫描或多实例不能重复入队。
- 第一版默认禁止同一计划重叠运行；错过触发的补跑策略明确展示并持久化，不无限补跑。
- Web/桌面仅编辑远端计划和查看历史；本地 scheduler 排除迁移后的远端计划。
- 迁移已有远端自动化保留来源 ID，重复迁移幂等；控制面接管成功后停用本地触发。

验收：关闭全部客户端后远端计划照常触发；两个客户端及重复调度扫描不会重复运行；控制面重启后按既定错过策略恢复；停用计划不再生成新运行。

### 3. 远端会话、工作区和成果

- 会话持久工作卷或快照版本由控制面索引，多轮 follow-up 创建新 run 并延续工作区。
- 同一工作区写入串行化；明确任务失败、取消后的产物与工作区状态。
- 在原工作台查看文件、差异、日志和下载产物；桌面显式审阅后应用到本地。
- 增加对象存储接口、大小限制、保留期和回收，不默认同步本地目录。

验收：第二轮能读取第一轮文件；Web 与桌面看到同一历史和成果；成果导入不会无提示覆盖本地改动。

### 4. 控制面资源治理与管理后台

- Worker 注册、容量、心跳、离线和排空状态；控制面按能力、槽位、配额与镜像分配任务。
- 租约与 attempt 隔离，旧 Worker 不能提交结果；副作用不明的失败不自动重跑。
- 正式身份认证、邀请、空间权限、令牌撤销、模型渠道与预算；管理操作审计。
- 管理后台查看队列、计划、运行、节点、失败原因与资源消耗，复用同一权威 API。
- 容器 Codex 在 Pig 链路稳定后接入，与执行位置保持独立。

验收：超配额任务被服务端拦截；节点排空不再接新任务；Worker 故障后没有重复执行或残留容器；账号之间无法读取或控制对方任务。

### 5. 发布验收

- 本地一键启动，数据库迁移及备份恢复，固定镜像版本，Linux 部署说明。
- 10 个内测账号、3 个并发运行，覆盖排队、取消、断线、重启、定时触发和资源回收。
- Web/Electron 同一套功能回归；桌面打包与启动诊断，签名和自动更新单独配置。

## 执行与凭据边界

Agent 容器非 root、只读根文件系统、受限 CPU/内存/PID/磁盘和运行时长；只允许受控工作区写入及网络出口。长期模型密钥保留在网关，容器只获得绑定运行且可失效的短期令牌。当前个人 DeepSeek Key 保留本机，不自动上传成平台共享密钥。

首版面向邀请制小团队，普通 Docker 不能视为完整的敌对多租户安全边界。公开注册、支付、多区域、Kubernetes、移动端和插件市场暂不纳入本阶段。
