# 云端个人设置、记忆与搜索

云端用户数据保存在 PostgreSQL，按登录账号隔离。Web 使用 HttpOnly 会话；桌面通过现有 `/api/remote` 服务端代理访问同一组接口，凭证不返回前端。

## 设置与生效范围

`GET /v1/settings` / `PUT /v1/settings` 支持：

| 字段 | 默认值 | 行为 |
| --- | --- | --- |
| `requireApproval` | `true` | 新任务需要写操作审批 |
| `networkPolicy` | `ask` | 外网访问申请审批；可设为 `blocked` 禁止访问 |
| `memoryEnabled` | `true` | 私人任务上下文可使用本人保存的记忆 |

云端执行目标固定为远端容器，不接受切换宿主机等额外设置。设置保存后影响新任务和新建计划的执行默认值，已提交任务保留自己的快照。已有计划保留创建时的审批和网络策略；计划实际产生任务时读取本人当前启用的记忆。

Web 创建任务传入 `useUserDefaults: true`，未配置账号也使用审批开启的默认值。为保留原 API 兼容性，未保存设置且未传该标志的旧客户端保留原执行默认值。已保存设置的账号使用保存值；请求显式执行选项仍可覆盖默认值。幂等重试按原始请求比较，不因期间设置变更重新创建任务。

## 私人记忆与搜索边界

- `GET /v1/memory`、`POST /v1/memory {content}`、`DELETE /v1/memory/:id` 仅操作本人记录。每账号最多 50 条，每条最多 2,000 字符；实际上下文最多 16,000 字符。
- 私人记忆仅注入本人无项目任务或本人个人项目。协作项目不自动注入任何成员的私人记忆；协作续聊也重新执行此检查。
- 删除或禁用记忆影响后续上下文，不删除已经提交任务中的快照或已有回复。
- `GET /v1/search?q=...` 搜索可访问会话标题、用户输入与助手消息，最多 50 条。查询必须为 1–200 字符。按现有项目成员权限过滤，管理员身份不会单独获得私人会话的搜索访问权。

## 可复现验证

先按集群部署说明启动隔离的 `pig-agent-cluster` 环境（入口 `http://127.0.0.1:8892`），模型通道使用已有 mock 测试通道。不要针对真实用户环境运行该脚本。

```sh
pnpm exec vitest run apps/cloud/src/user-data.test.ts
pnpm --filter @pig-agent/cloud typecheck
node scripts/smoke-cloud-user-data.mjs
```

2026-09-22 实测：单元测试 4 项通过，Cloud TypeScript 检查通过；隔离集群 8 项真实 PG/API 检查通过。运行证据位于 `data/user-data-evidence/api.json`，包括审批开启时实际等待批准、审批关闭时无审批成功、设置快照、幂等重试、私人记忆与协作续聊隔离、搜索隔离和新计划默认值。

脚本创建独立测试账号和项目，不修改现有账号或模型通道。结束时取消测试任务、禁用测试账号与计划、清理其会话凭证和个人设置/记忆；任务与项目保留用于追溯。本验证使用本地 mock，不代表生产模型容量或性能，界面截图验收另行执行。
