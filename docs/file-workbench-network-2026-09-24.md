# 文件工作台与联网修复

目标：右侧浏览文件，中间展示及编辑内容，随时返回对话。保存须保留权限和版本边界，运行中禁止冲突写入，过期编辑返回冲突。手机采用单面板切换。

联网：从真实线上失败任务定位 DNS、连接、授权或工具误用，保留一次授权及 SSRF 防护，禁止以打开任意 shell 网络代替修复。验证公网成功、超时、私网拒绝、取消及审批阻塞。

实施分工：Cursor 负责文件工作台（contracts → 后端版本编辑 → Web/本机右栏及中间编辑器，失败行为测试与浏览器验收）；Codex 负责联网调查、修复、最终集成和验证。Cursor 禁止推送及部署生产、不读取密钥；由 Codex 完成独立验收后部署。不得修改对方负责文件，若冲突先在记录中说明。

Cursor 文件部分要求：
- 不仅改 artifact 内容：用户保存的编辑必须实际进入后续任务工作区，同时保留原成果和版本历史。可采用显式 overrides 在 checkpoint 恢复后应用，带版本比较，作者归属与会话写权限。禁止覆盖并发任务正在使用的工作区。
- 原有聊天历史、审批、日志可切回，不删除。右侧显示文件，点击后中间打开可编辑文本（有保存、未保存、冲突、只读、大文件/二进制说明）。移动端可返回列表或对话。
- 先读 AGENTS.md 和 docs/architecture.md；安全与一致性先失败测试。相关测试、类型检查和构建。不要提交或推送，由 Codex 集成。

## 文件实现独立审查（已处理，结果见最终验收）

- 当前 file-edits.ts 未事务锁定会话，两个保存都可成功、与 follow-up 排队竞争。必须和 follow-up 使用相同 conversation FOR UPDATE 锁，在事务内重新查权限、活动任务、版本并写历史。测试并发一个成功一个冲突；禁止先读后无条件 upsert。
- 第一次保存不能以空字符串作为当前版本，须从该会话最新成果读取真实内容；刷新后 GET 必须返回当前编辑内容和 revision。原成果不修改，编辑有独立版本。
- overrides 不能永远覆盖后续任务产物：只应用比当前 checkpoint 更新的编辑，避免 Agent 新改动被上一轮人工稿回滚。需要行为测试。
- 编辑 path 必须校验并拒绝 .pig/.git/越界/二进制/超限 UTF-8 字节，不能只看 JS 字符长度。工作区恢复与 overrides 写入拒绝符号链接；不要允许覆盖技能私有资源。
- 本机保存缺少锁，历史文件按 path 混用不同 workspace。按 root+path 序列化 compare-and-write、按工作区隔离版本，并保证失败不报告成功。不要绕过现有 file helper 的沙箱写入边界。
- 前端保存异步返回要防会话/文件切换串写；脏稿切换提示；刷新已保存内容；右侧不要同时重复全文预览。

## 联网调查与实现证据

服务器原版本的一次资讯任务中，TechCrunch 和 Hacker News 均已消费审批，但错误被笼统归为“网络失败”，模型随后误解释为没有批准。

确定的代码根因：`publicIPv4` 错把 `192.0.0.0/16` 全部拒绝（应拒绝其中的特殊用途 /24 段），TechCrunch 的公网 `192.0.66.220` 被误拦；`198.51.0.0/16` 也过宽。已收紧到实际保留网段，保留私网、回环、元数据、文档、基准测试及组播保护。

- 增加 DNS/连接/TLS/超时/取消的稳定错误码与安全文案，不泄漏底层错误、密钥或响应正文。
- 多公网 IPv4 仅在 TLS 建立前失败时切换，不重放已发送 HTTP 请求；解析和连接受总超时约束。
- 公共加密 DNS 支持固定 IP、保留证书校验的 AliDNS 选项。腾讯云覆盖文件选择已在宿主网关内验证可达的解析器，仍对所有目标 A 记录执行公网校验并固定连接 IP。
- 实测网关同容器：腾讯 200（81ms）、TechCrunch 200（543ms）。旧实现同环境对 TechCrunch 错误拒绝。仅运行探针，未调用真实模型。
- Hacker News 与 Wikipedia 从服务器仍连接超时，包括切换加密 DNS 后；不能承诺当前服务器能访问所有外部站点，不能通过取消沙箱来改变出站网络可达性。
- 固定 `1.1.1.1` 的旧公共解析模式从该主机实测约4秒超时，不能作为此环境的默认修复方案。

解析服务参考：[阿里公共 DNS](https://www.alidns.com/)。实际可达性以 `data/network-workbench-review/` 的现场探针结果为依据。

可复现诊断（只供运维，不是 Agent 绕过审批的工具）：

```sh
NETWORK_DNS_MODE=public NETWORK_DNS_PROVIDER=alidns \
  node --import tsx scripts/probe-network.mjs https://www.qq.com/ https://techcrunch.com/
```
