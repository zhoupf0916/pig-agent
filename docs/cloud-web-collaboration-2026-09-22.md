# Web 云端边界与共享会话

## 产品边界

Web 面向使用者，直接由控制面提供前端与认证 API；用户无需安装本机服务。任务全部进入控制面队列，由 Runner 执行。桌面保留本机工作台，并通过「共享项目」进入同一云端协作界面。云端数据不由桌面本地镜像决定。

8797 等旧本机 Web 服务默认仅跳转到配置的控制面，不启动本机执行器或定时器，本机 API 返回410。`PIG_LOCAL_WORKBENCH=1` 只用于开发与既有桌面集成测试；不应将该进程公开部署。

## 协作流程与验收

登录 → 加入组织/创建共享项目 → 创建会话 → 成员看到同一消息与作者 → 任一编辑者跟进 → Runner读取共享历史及项目背景 → SSE向多端同步 → 查看审批/成果。

- 权限沿用组织管理员/编辑者/只读角色，控制面逐次校验。
- 同一会话同时只允许一轮运行。多人同时提交由数据库事务裁决，冲突返回409，前端保留输入；不静默覆盖上下文。
- 会话SSE跨运行持续订阅，初始快照与持久事件恢复；成员被移除或登录失效时断开。
- 模型上下文沿用已有最近40条用户/助手历史上限与工作区版本；不承诺无限上下文，也不自动拼接项目内其他会话内容。
- Browser登录使用HttpOnly会话cookie；桌面沿用受保护的控制面令牌。系统管理员接口继续独立鉴权。

## 启动与账号

```sh
pnpm cloud:up            # 控制面、数据库、网关、Runner，Web http://127.0.0.1:8890/
pnpm desktop:dev        # 桌面；设置远端连接后选择“共享项目”
pnpm cluster:up         # 双控制面+双Runner，隔离验收 http://127.0.0.1:8892/
```

Web 登录可使用现有访问令牌，或管理员在管理端发放的账号邀请凭证；登录成功后交换为12小时HttpOnly Cookie，不把令牌留在localStorage。组织邀请码用于已登录账号加入组织，与账号邀请不是同一种凭证。桌面继续使用系统保护的远端访问令牌；同一个账号可在多端登录，共享项目权限由控制面判断。

本地平台的访问凭证在忽略提交的 `data/cloud-local/access.txt`。部署到服务器时使用正确的域名与TLS代理，并通过环境变量 `WEB_PUBLIC_ORIGIN=https://你的域名` 固定公开源；代理保留Host，禁用SSE缓冲，适当延长读超时。Docker Compose当前仅绑定loopback，不是已公开到互联网的生产部署。

## 已知边界

- 共享的是同一会话的对话历史与工作区版本、项目说明。不会无边界地合并项目内所有会话；后续模型输入仍有历史条数与token预算限制。
- 同会话当前串行执行；运行期间可查看并编辑下一条输入，待结束后再发送。不提供多人同时修改同一条消息或实时文档协作。
- 本轮多端证据来自同一Mac上的独立Chrome账号、手机尺寸浏览器与真实Electron，不推断为跨公网或生产容量测试。
- 云端统一模型仍由管理员配置；本机专家、技能、插件及computer use没有自动分发到所有Runner。桌面原有功能保留，Web本轮聚焦共享任务、审批与成果。
- 尚未配置公网域名、TLS、公开注册/计费；不宣称生产高可用或exactly-once。

最终自审补充：管理员降权后既有运行SSE关闭，后续私有读取404；同页退出A并登录B后释放A的迟到响应，旧项目不会回填。证据见 `docs/evidence/cloud-web-2026-09-22/`。最终静态资源已更新到8890，桌面已重启并实际打开共享项目，原本机数据与密钥保留。未推送GitHub或部署公网。
