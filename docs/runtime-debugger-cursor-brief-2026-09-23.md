## 第一阶段：观测基线与开发者工具

在 Electron 工作台的页签（tab，用户称 tag）中加入「开发者」。优先挂到当前对话的详情/检查器页签体系，可收起，不挤占正常对话主区；先检查现有组件，统一白蓝视觉。不是只打开 Chromium DevTools 就算完成。

开发者页至少包含：

1. **请求列表（类似浏览器 Network）**：时间、类型、状态、耗时、方法、脱敏后的 URL/提供商/模型、请求 ID。区分 UI→本机服务、控制面→Runner、模型请求、工具执行；有搜索、失败/进行中筛选、自动滚动开关及清空视图。
2. **对话调用瀑布图/时间线**：用 session/conversation、run、turn、trace、span、parent span 关联；显示排队、领取、沙箱准备、模型首字/完整生成、工具执行、审批等待、结果交付和界面展示等实际测量段。本机单调时钟测时，跨节点不得直接相减未同步时钟。无法测量时明确“未采集”，不能用假数值补齐。
3. **调用详情**：每轮实际发给模型的 messages/工具 schema 和可用参数，实际返回的文本/tool calls/usage/finish reason（提供商未返回就留空）；工具参数、stdout/stderr、结果、退出码、错误与取消原因；支持折叠、搜索、受限复制和脱敏导出。不要声称获取模型内部隐藏思维。
4. **真实执行环境**：本机/远端、实际引擎与模型、Runner ID、沙箱 requested/effective/backend（Seatbelt/Bubblewrap/host）、工作区、网络权限与审批记录。必须来自实际执行端事实，不能只显示 UI 开关推测。沙箱失败继续 fail closed。
5. **类似 Console 的事件/错误视图**：等级、来源、时间、关联调用，定位失败请求；流式记录增量追加，不能每个 token 全量持久化或重绘。

普通 Electron DevTools 可以另有“打开页面开发工具”入口作为补充，但不能替代上述服务端调用追踪。模型调用常发生在 Node/Runner，不在渲染进程，必须在执行端埋点并用受控协议传给 UI；不要用全机抓包或放宽 Electron 安全策略。

### 调试数据安全与开销

- contracts 先定义公共协议，再改发送和消费方。Web 不导入 Electron/Node/server 实现。
- 在采集/存储入口脱敏 Authorization、Cookie、Set-Cookie、API Key、token、URL 中敏感参数；日志、测试输出和导出均不出现明文凭据。
- 默认记录必要元数据；完整内容调试由当前用户显式开启，并说明范围、生效时间和保留方式。不偷偷记录所有账号会话。输入输出含私密业务数据，查看与导出继承原会话/项目权限。
- 限定单条大小、总条数、保留量，超限显示截断原因；开启与关闭都能测量额外开销。清空视图不删除执行结果或运行审计。
- 不开放任意 IPC、任意文件读取、任意 URL 代理；远端数据必须按用户/项目鉴权。退出或切换账号立即清理旧视图，旧异步响应不能串账号。

先对鉴权/脱敏/数据隔离/重连去重写失败的行为测试，再实现。

## 第二阶段：P0 体感链路

- 发送立即反馈、消息只插入一次；测量确认时间，不伪造执行开始。
- SSE 端到端检查缓冲、首字延迟、增量合并、Markdown 重绘、滚动保持。降低无效刷新，日志和 token 分批更新。
- 统一排队/准备/思考/工具/审批/完成状态；以控制面/执行端为事实来源。按事件序号断线续传，避免漏事件和重复显示；多端一致。
- 审批严格逐项阻塞，批准后恢复原操作，拒绝/取消停止后续副作用；等待文案及时清理。停止覆盖模型流、工具进程和待执行批次。
- 明确 Codex 引擎边界：已有 recoverability 测试在基线失败，runSessionTurn 中 codex 被静默转换为 pig。先确认现有产品约束；至少消除 UI/实际引擎的错误声明和静默替换，保留安全边界，不靠删测试或放宽断言交付。

## 第三阶段：P1/P2 效率与韧性

- 测量 Runner 调度间隔、进程启动、沙箱准备、工作区恢复，按证据优化；安全复用不能串文件/凭据。
- 减少重复读取和模型往返，独立只读工具受控并行；有副作用的操作保留审批、顺序和取消边界。
- 控制历史/工具输出体积，压缩时保留目标、约束、决策、文件状态、审批和待办。长对话不反复遗忘或重做。
- 默认执行过程简洁，原始日志进开发者页；成果能直接定位。
- 故障区分限流/网络/工具/节点失联，安全重试不重放未知副作用；保留已完成产物。
- 相同任务集比较可用模型的首字/总耗时/成功率/费用；不擅自使用真实 Key 做大量性能测试。功能回归默认 mock，真实模型基准若涉及额外费用先报告条件。
