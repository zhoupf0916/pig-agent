# macOS 客户端电脑操作

电脑操作通过 Electron 主进程与专用原生 helper 执行，Web 服务和 Runner 不具备此桥接。客户端设置中的启用只对当前进程有效；每次观察或输入仍出现本机确认对话框。停用立即撤销尚未执行的请求，取消任务会终止等待中的原生请求。已经发出的系统输入无法撤销。

支持观察应用的辅助功能元素、截图预览、左键点击、Unicode 输入、基本导航按键和垂直滚动。模型获得辅助功能树中的位置、尺寸、文本，截图只供用户预览；本版本没有把截图自动交给视觉模型。密码输入框的辅助功能值会隐藏，但屏幕画面仍可能包含敏感内容。

先打开目标应用。可说“观察 TextEdit 并……”使用准确的运行中应用名，或先将目标应用置于前台。禁止操作 Pig Agent / Electron 自身以及系统权限设置应用。观察返回 60 秒有效、只可使用一次的 observationId；每次输入后须重新观察。点击限定在该应用的窗口内，输入前再次激活和检查目标应用。

macOS 系统设置 → 隐私与安全性中需要授权辅助功能；截图额外需要屏幕录制。应用不会自动授予系统权限。设置显示 Electron 的权限状态，helper 在实际调用时会再次检查权限；若系统归属不同，实际调用会明确拒绝，不会仅依据设置指示执行。

`pnpm desktop:build` 在 macOS 构建时使用 Xcode Command Line Tools 编译 helper，打包到 runtime。安装后的客户端不需要编译工具。仅开发模式允许首次调用时编译缺失的 helper；非 macOS 版本显示不可用。

## 2026-09-22 验证

- 原生 Swift helper 编译通过；桌面构建成功。
- 4 个边界测试通过：非桌面拒绝、参数和目标限制、默认关闭/取消/撤销、启用确认等待期间撤销不可重新启用。
- 隔离 Electron 测试窗口真实运行，屏幕权限 granted、辅助功能 false。helper 观察返回权限拒绝；没有尝试向用户应用输入，也没有绕过 macOS 权限。测试 harness 只对独立测试窗口替代了应用确认对话框，生产代码不存在自动确认开关。
- 证据：`data/computer-use-evidence/native-smoke.json`、`native-test-window.png`。截图已经人工查看。
- 点击、键入、滚动成功路径仍需用户通过 macOS 授权后在无害测试应用中验证，不能把当前权限拒绝测试视作完整输入验收。
