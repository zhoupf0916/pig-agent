# 工作台、项目与专家交互重构

## 目标与验收
保留白蓝色设计、完整导航和项目协同权限边界。借鉴 JoyDesk 的清晰信息层级：主要入口固定、项目上下文可见、专家卡片用于选择而非堆叠长表单。

- 专家和技能：分类、搜索、创建入口；卡片只显示用途；详情与编辑进入聚焦对话框；保存后可直接开始任务。
- 项目：项目列表代替下拉选择；桌面项目入口常驻上下文栏，移动端抽屉；项目首页展示工作区、对话入口和最近对话。
- 审批：本机界面只展示首个待批操作；说明执行暂停、批准后继续。原生沙箱通过真实状态接口检查。
- 移动端：创建/详情可滚动，无横向溢出，Esc与关闭回到触发入口。

## 实现
CloudResourcesPanel 新增真实本地过滤、资源详情/创建对话框（焦点约束），复用后端实际保存与模型草稿接口。CloudWorkspace 新增项目树和项目总览，工作区按钮打开现有真实版本浏览器。原审批、日志、成果、权限判断均保留。
