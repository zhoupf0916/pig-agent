# 一句话创建专家与技能

专家页提供「一句话创建专家」，设置的独立「技能」区域提供「一句话创建技能」。输入用途后，后端使用设置中的 Pig Chat Completions 模型生成草稿；生成请求不提供工具，90 秒超时，最多 4000 输出 token。即使任务默认使用 Codex 或远端，此辅助生成功能仍使用本机配置的 Pig 模型。

草稿包含名称、简介和指令/步骤，可编辑；点击「确认创建」前不保存。模型不可用时保留输入、显示错误，并支持手动填写。生成可能消耗已配置提供商额度。API 返回模型标识，不返回密钥或原始提供商错误。

用户技能写入 `DATA_DIR/skills/<name>.md`，桌面端使用应用的数据目录，不修改应用包中的内置技能。标识为 1–80 位小写英文、数字、连字符，重复名称不覆盖。读取时合并内置、用户技能和已启用插件技能；创建后列表轮询更新，Agent 的 `list_skills`/`load_skill` 即时可用。专家保存使用现有专家存储与权限边界。

验证：`pnpm exec vitest run apps/server/src/routes/resource-drafts.test.ts apps/server/src/agent/skills.test.ts apps/server/src/agent/openai.test.ts`，覆盖草稿不保存、禁用工具、格式校验、错误脱敏、用户目录保存、重复和内置名称保护、路径穿越拒绝。前端/后端 TypeScript 检查通过。
